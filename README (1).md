PROJECT 3: SQL DATA ANALYSIS
##  Overview
This project focuses on analyzing an e-commerce dataset using SQL queries to extract meaningful insights from the data. Various SQL operations were 
performed to understand customer orders, product sales, revenue generation, and payment trends.

## Objective
To analyze a dataset using SQL by applying querying, filtering, grouping, sorting, and aggregation techniques to generate useful business insights.

## SQL Analysis Process
* Retrieved dataset records using SELECT queries
* Applied WHERE clause for filtering specific data
* Used ORDER BY to sort results efficiently
* Grouped data using GROUP BY for better analysis
* Performed aggregations using COUNT(), SUM(), and AVG()
* Analyzed sales, revenue, payment methods, and order trends

## Tools & Technologies
* SQL
* SQLite Online
* Basic SQL Querying Techniques

## Key Insights
* Calculated total number of orders
* Analyzed total revenue generated
* Identified top-selling products
* Found the most used payment methods
* Evaluated average order values
* Performed customer order trend analysis

## Skills Gained
* SQL Fundamentals
* Data Querying
* Data Filtering
* Data Grouping
* Aggregation Functions
* Dataset Analysis using SQL

## Outcome
Successfully analyzed the dataset using SQL queries and extracted valuable insights through filtering, grouping, sorting, and aggregation operations. This project improved practical understanding of SQL-based data analysis and querying techniques.
